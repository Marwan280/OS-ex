## Description

This project contains the solutions and code for "Assignment 2".This assignment is useful to practice the following concepts:

Creating processes using fork()

Executing programs in the background

Managing processes (stop, pause, resume)

Compiling multi-file programs and understanding the linker's role

Examining dynamic libraries loaded at runtime by the loader

## Installation

To run the programs, you need:

- A Linux environment (Ubuntu recommended)
- GCC installed
